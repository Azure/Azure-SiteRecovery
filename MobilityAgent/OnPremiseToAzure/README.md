# On-Premises-to-Azure (V2A)

## Mobility Agent Releases

V2A Mobility Agent releases provide full installers used to install or upgrade the agent on protected machines.

- [V2A Mobility Agent download links](AgentDownloadLinks.md)

The download page identifies the available agent version for each supported operating system. Refer to the applicable Azure Site Recovery support matrix before installation or upgrade.

## Kernel Module Updates

For Linux kernel compatibility added between full agent releases, see:

- [Common Kernel Module Updates](../KernelModuleUpdates/README.md)
- [V2A supported-kernel lists](SupportedKernels)

The `SupportedKernels` version folders contain kernel module update information. They do not identify full V2A Mobility Agent releases.
