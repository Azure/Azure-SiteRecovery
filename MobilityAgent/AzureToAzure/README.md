# Azure-to-Azure (A2A)

## Extension Releases

Azure-to-Azure Mobility Service releases are delivered and managed as Azure VM extensions. This scenario does not use the downloadable V2A Mobility Agent installers.

## Kernel Module Updates

For Linux kernel compatibility added between extension releases, see:

- [Common Kernel Module Updates](../KernelModuleUpdates/README.md)
- [A2A supported-kernel lists](SupportedKernels)

The `SupportedKernels` version folders contain kernel module update information. They do not identify A2A extension releases.
