# V2A Mobility Agent Releases

On-premises-to-Azure (V2A) Mobility Agent releases provide full installers used to install or upgrade the agent on protected machines.

## Downloads

- [V2A Mobility Agent download links](../OnPremiseToAzure/AgentDownloadLinks.md)

The download page identifies the available agent version for each supported operating system. Refer to the applicable Azure Site Recovery support matrix before installation or upgrade.

For Linux kernel compatibility added between full agent releases, use [Common Kernel Module Updates](../KernelModuleUpdates/README.md).
