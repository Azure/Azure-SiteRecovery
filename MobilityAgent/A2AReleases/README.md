# A2A Extension Releases

Azure-to-Azure (A2A) Mobility Service releases are delivered and managed as Azure VM extensions. This category is for A2A extension release information; it does not provide downloadable V2A Mobility Agent installers.

For Linux kernel compatibility added between extension releases, use [Common Kernel Module Updates](../KernelModuleUpdates/README.md).

## Related information

- [A2A kernel module supported-kernel lists](../AzureToAzure/SupportedKernels)

The supported-kernel lists are classified under common kernel module updates, even though the manifests remain at their existing customer-facing paths.
